The central shared result

At fixed metallic Sr fractions, both Ti and La have approximately constant T1T. Their rate coefficients grow similarly toward the Mott boundary. With the source's geometric and hyperfine assumptions, that pattern favors enhanced metallic density of states over a prominently growing extra AF-q component. It does not establish that every finite-q correlation is absent.

Composition convention

Both versions use La1−xSrxTiO3, with x the Sr fraction. The insulating LaTiO3 endpoint lies at x = 0, so approach from the metal runs toward small x. The companion Tokura source 341 uses the complementary La fraction in Sr1−xLaxTiO3. Translating this convention prevents a false conflict between their trends.

Source 338 is an additional current file absent from the older catalog; its direct current hash is explicitly recorded in the present inventory.
